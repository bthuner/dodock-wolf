Since [#136](https://github.com/bthuner/dodock-wolf/issues/136), Wolf builds next to Frappe Cloud v2, not over it. This section says what that ground is. Dokos will operate its own, with dokopilot, its fork of Pilot, in the servers: so this is also the platform Dokos will have to run. The illustrated version is the [making-on](https://bthuner.github.io/dodock-wolf/making-on/).

## In one paragraph

Frappe Cloud v2 is six applications. **Central** is one global Frappe site: teams, billing, the console. Each region has an **Atlas** (a Frappe site that runs Firecracker virtual machines on physical hosts, with a proxy in front) and a **Cargo** (a Frappe site that builds the images, runs the S3 storage, and runs the region's telemetry store). **Datum** is that store's write API, in front of ClickHouse. **Beacon** is one global Frappe site that reads every region's ClickHouse and pages people. A customer server is one virtual machine that runs **Pilot**, which manages the bench and its sites. The applications never share a database: they talk over HTTPS, with short Ed25519 tokens, HMAC-signed webhooks, and the virtual machine's metadata service.

## Three planes

| Plane | How many | Applications | Owns |
|---|---|---|---|
| Global | one site each | Central, Beacon | Teams, capabilities, billing, the console; incidents, service levels, paging, the status page |
| Region | one of each per region | Atlas, Cargo, Datum + ClickHouse, the proxy, the WireGuard gateway, Garage (S3) | Hosts and virtual machines, networks, routes and the wildcard certificate; images, buckets; telemetry |
| Server | one virtual machine per customer server | Pilot, the bench, the sites, MariaDB, Redis, nginx | Apps, sites, backups, updates, custom-domain certificates, every log |

## Who owns what

| Question | Owner | Not |
|---|---|---|
| Who is this team, and may this person do that? | Central (`Team`, 18 capabilities) | The regions see only a tenant number |
| Does this server exist, and is it running? | Atlas (`Virtual Machine`), mirrored in Central | Pilot |
| Which sites and apps does this server have? | Pilot (`bench.toml`, files) | Central has no Bench DocType and no deployment record |
| Where does this hostname go? | Central decides (`Site Domain`), the region's proxy applies | Atlas' site is not on the path |
| Who holds this site's certificate? | The proxy for the region's wildcard names; the server for a custom domain | Central |
| What did this server measure? | Datum's ClickHouse, per region | Central |
| Is something wrong with the platform? | Beacon | A single failing site or server: Pilot tells its owner through Central |
| What happened inside the bench? | Nobody outside the server | See [Inside a customer server](/internals/customer-server) |
