La Wolf App (`dodock_wolf`) tourne sur un site Frappe ou Dokos. Ce site devient le site Wolf
**central** : les agents lui envoient leurs données, les règles s'y exécutent, et la Wolf UI y est
servie sur `/wolf`.

## Prérequis

- Frappe 15 ou Dokos (Dodock 5). Testé sur Dodock 5.18, MariaDB 10.6 et Postgres 16 et 17.
- Node 20.19 ou ultérieur sur le bench, pour le `bench build` de la Wolf UI.
- Un planificateur qui tourne chaque minute (voir plus bas).

## Installation

```bash [bench]
cd ~/frappe-bench
bench get-app https://github.com/bthuner/dodock-wolf
bench --site wolf.example.com install-app dodock_wolf
bench build --app dodock_wolf   # lie les fichiers statiques et construit la Wolf UI (/wolf)
bench set-config -g scheduler_tick_interval 60
```

Redémarrez ensuite le processus du planificateur.

L'installation crée :

- les rôles **Wolf Manager** (voit et configure tout) et **Wolf User** (lecture seule) ;
- un **jeton d'enregistrement** aléatoire dans **Wolf Settings**, utilisé par les agents pour
  s'enregistrer ;
- les [règles d'alerte prédéfinies](/fr/alerts/presets), sans canal.

## Rythme du planificateur

Les règles d'alerte, les agrégats et les envois des satellites de Wolf sont planifiés chaque
minute. Frappe 15 et Dodock ont par défaut un tick toutes les 4 minutes.

::warning
Si `scheduler_tick_interval` n'est pas réglé sur `60`, une alerte peut arriver jusqu'à 4 minutes
en retard, et « déclencher après 3 évaluations » signifie 12 minutes. La page **Monitoring** de la
Wolf UI affiche le rythme en vigueur.
::

## La Wolf UI

`https://<site>/wolf` est l'interface des opérateurs, une application Vue construite sur
frappe-ui. Elle réutilise la session Frappe : les invités sont renvoyés vers la page de connexion,
les utilisateurs sans **Wolf User** ni **Wolf Manager** reçoivent une erreur 403. Desk conserve
les DocTypes de configuration ; une vue que la Wolf UI n'a pas encore renvoie vers Desk.

## Langue

Desk affiche Wolf dans la langue de chaque utilisateur (**My Settings → Language**, « Mes
paramètres → Langue » en français). L'anglais et le français sont disponibles : libellés des
champs, descriptions, boutons et messages. Les noms de DocType, les types d'événements, les noms
de métriques et les valeurs des listes de choix restent en anglais, comme dans le code. La Wolf UI
et la phrase des règles sont en anglais pour l'instant.

## Signaux sans agent

Le site Wolf se surveille lui-même dès que l'application est installée : Scheduled Job Logs en
échec, Error Logs et sauvegardes en échec, connexions Desk échouées, connexions privilégiées depuis
une nouvelle IP ou un nouveau pays, attributions de rôles, engorgement de l'Email Queue et
changements à risque dans l'application. Chacun peut être désactivé dans **Wolf Settings**. Voir
[Signaux du site](/fr/security/site-signals).

Pour obtenir les mêmes signaux depuis les autres sites du bench, installez-y aussi l'application,
en tant que [satellites](/fr/install/every-site).

## Mise à jour

```bash [bench]
bench update --apps dodock_wolf   # ou : cd apps/dodock_wolf && git pull
bench --site wolf.example.com migrate
bench build --app dodock_wolf
```

Les migrations n'écrasent jamais les règles prédéfinies que vous avez modifiées. Un
`bench migrate` est enregistré comme déploiement sur la chronologie de Wolf.
