Lancez les commandes en tant qu'utilisateur `wolf-agent`, propriétaire de la configuration :
`sudo -u wolf-agent wolf-agent <command>`.

Options globales : `--config PATH` (ou `$WOLF_AGENT_CONFIG`), `-v`.

| Commande | Rôle |
|---|---|
| `register --url URL --token TOKEN [--bench PATH]...` | Enregistre l'hôte, découvre les benches, écrit la configuration. |
| `run` | La boucle du démon. C'est ce que lance systemd. |
| `discover [--bench PATH] [--platform auto\|press\|generic]` | Affiche ce que trouve la découverte des benches. |
| `check [--from-start] [--status] [--platform …]` | Collecte une fois et affiche la charge utile JSON. Rien n'est envoyé. L'état du chien de garde part sur stderr. `--status` demande aussi au site son état de santé. |
| `mark-deployment --bench NAME [--site S] [--note TEXT] [--silence 15m]` | Place un marqueur de déploiement sur la chronologie Wolf. `--silence` ouvre aussi une fenêtre de maintenance qui coupe les notifications pour ce bench ou ce site. |
| `test-fallback` | Envoie un message de test via les canaux de secours du [chien de garde](/fr/agent/watchdog). |
| `demo press [--root DIR] [--days N] [--no-live] [--cycle MIN] [--configure]` | Écrit un serveur d'applications Press simulé que cet agent lit : des jours d'historique, puis du trafic et des incidents en direct. Pour les démos et les tests uniquement. |

## Marquer un déploiement

```bash [deploy.sh]
sudo -u wolf-agent wolf-agent mark-deployment --bench frappe-bench --site erp.example.com \
  --note "ERPNext v15.42 + custom app 2.3" --silence 15m
```

Le marqueur est un événement `deployment`. Les règles avec **Require recent deployment** ne se
déclenchent qu'après un déploiement, et les incidents sont liés au dernier déploiement de leur
périmètre. Le texte passé avec `--note` est envoyé tel quel, sans [nettoyage](/fr/agent/scrubbing).

Les tâches Press et Pilot, ainsi que `bench migrate` sur les sites qui exécutent la Wolf App, sont
marquées automatiquement.

## Lancer une démo

`demo press` dispose un serveur d'applications Press sous `--root` (par défaut
`/home/frappe/demo-press`) : 3 benches, 8 sites dont deux avec un domaine personnalisé, le
`jobs.sqlite3` de l'agent Press, un journal d'accès nginx au format de Press et un auth.log. Les
sites ne sont que des noms : rien ne tourne derrière. Utilisez un hôte ou un conteneur dédié,
enregistré sous un nom à lui.

```bash [hôte de démo]
wolf-agent register --url https://wolf.example.com --token TOKEN --hostname f1-demo-press --platform press
wolf-agent demo press --configure   # mode Press sur la démo, contrôles sans rien derrière coupés
wolf-agent run &                    # l'agent d'abord : il doit ouvrir les fichiers quand ils sont vides
wolf-agent demo press               # 7 jours d'historique, puis un cycle d'incidents toutes les 30 minutes
```

La commande attend que l'agent suive chaque fichier, puis écrit l'historique, qui arrive dans Wolf
par la découverte, les lecteurs de journaux et les parseurs de l'agent. Les métriques d'hôte
passées, que l'agent mesure en direct, passent par sa file d'attente sur disque. Chaque cycle
comprend une migration Press suivie de 4 minutes de 502, une trace d'erreur de requête, une tâche
planifiée en échec, un worker tué, une attaque SSH par force brute (une sur trois réussit), un
balayage d'attaque web et, un cycle sur deux, une tâche Patch App en échec.

Les règles regardent les dernières minutes : les incidents s'ouvrent pour les cycles en direct, pas
pour l'historique. `bench --site SITE generate-demo-press --agent-config PATH` fait la même chose
depuis un bench où l'agent est installé, et `--webhook URL` y envoie aussi les alertes de la démo.
La [page Développement](/fr/reference/development) lance le tout dans Docker.

## Voir la charge utile

```bash [hôte]
sudo -u wolf-agent wolf-agent check --from-start | jq '.events[] | {type, category, title}'
```

`--from-start` lit les journaux depuis le début au lieu des positions enregistrées, ce qui sert à
tester un parseur sur un fichier existant. `check` n'envoie jamais rien et ne déplace jamais les
positions.
