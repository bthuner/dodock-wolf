`wolf-agent register` écrit `/etc/wolf-agent/config.json` (mode 0600, propriétaire `wolf-agent`).
Modifiez-le pour ajouter des journaux ou remplacer la découverte, puis redémarrez le service :

```bash [hôte]
sudo systemctl restart wolf-agent
sudo -u wolf-agent wolf-agent check   # lance chaque contrôle une fois, TLS compris
```

Utilisez un autre fichier avec `--config PATH` ou `$WOLF_AGENT_CONFIG`.

## Exemple complet

```json [/etc/wolf-agent/config.json]
{
  "url": "https://wolf.example.com",
  "agent_id": "WAG-0001",
  "agent_secret": "…",
  "hostname": "bench-01",
  "push_interval": 30,
  "spool_dir": "/var/lib/wolf-agent/spool",
  "verify_tls": true,
  "auth_log": null,
  "collect_host_metrics": true,
  "platform": null,
  "press": {"agent_dir": "/home/frappe/agent", "nginx_access_log": "/var/log/nginx/access.log",
            "rediscover_interval": 60, "deployments": true},
  "pilot": {"deployments": true, "api_url": null, "token": null, "jwt_secret": null},
  "benches": [
    {"name": "frappe-bench", "path": "/home/frappe/frappe-bench", "sites": ["a.example.com"],
     "logs_dir": "/home/frappe/frappe-bench/logs", "nginx_access_log": "/var/log/nginx/access.log",
     "redis_queue": "redis://127.0.0.1:11000"}
  ],
  "extra_logs": [{"path": "/var/log/myapp/error.log", "parser": "traceback", "bench": null, "site": null}],
  "rq": {"long_job_minutes": 30},
  "backups": {"enabled": true, "interval": 600, "press": false, "dirs": {}},
  "tls": {"enabled": true, "interval": 3600, "port": 443, "timeout": 5, "connect_host": null,
          "domains": ["status.example.com"], "exclude": []},
  "mariadb": {"enabled": true, "cli": null, "host": null, "port": null, "user": null,
              "password": null, "defaults_file": null},
  "processes": {"enabled": true, "manager": "auto"},
  "versions": {"enabled": true, "interval": 3600},
  "site_settings": {"enabled": true, "interval": 3600},
  "suricata": {"enabled": true, "eve_log": null, "max_priority": 3},
  "wazuh": {"enabled": true, "alerts_log": null, "min_level": 7, "exclude_groups": ["sca"]},

```

## Connexion

::field-group
  :::field{name="url" type="string"}
  Le site Wolf central.
  :::

  :::field{name="agent_id / agent_secret" type="string"}
  Écrits par `register`. Le site ne conserve qu'un hash du secret : pour remplacer un secret perdu,
  utilisez **Rotate secret** sur le formulaire Wolf Agent.
  :::

  :::field{name="push_interval" type="number"}
  Secondes entre deux envois. `30` par défaut.
  :::

  :::field{name="verify_tls" type="boolean"}
  Vérifier le certificat du site Wolf. `true` par défaut.
  :::

  :::field{name="spool_dir" type="string"}
  Positions de lecture des journaux, file des envois échoués (plafond de 50 Mo) et état du chien de
  garde (watchdog).
  :::
::

## Sources

::field-group
  :::field{name="platform" type="null | &quot;press&quot; | &quot;generic&quot;"}
  `null` détecte [Press](/fr/install/press) automatiquement, `"press"` le force, `"generic"` le
  désactive.
  :::

  :::field{name="benches" type="array"}
  Nom, chemin, sites, `logs_dir`, `nginx_access_log` (un chemin ou une liste) et `redis_queue` par
  bench. Rempli par la découverte ; modifiez-le pour la remplacer.
  :::

  :::field{name="auth_log" type="null | string | &quot;journal&quot; | false"}
  `null` détecte automatiquement, un chemin force un fichier, `"journal"` force journalctl, `false`
  désactive.
  :::

  :::field{name="collect_host_metrics" type="boolean"}
  CPU, mémoire, swap, charge et disque. `true` par défaut.
  :::

  :::field{name="extra_logs" type="array"}
  D'autres fichiers à suivre : `path`, `parser` (`traceback`, `scheduler`, `worker`, `nginx`,
  `auth`), et en option `bench` et `site`.
  :::

  :::field{name="pilot" type="object"}
  `deployments`, `api_url`, `token`, `jwt_secret`. Voir [Benches Pilot](/fr/install/pilot).
  :::

  :::field{name="press" type="object"}
  `agent_dir`, `nginx_access_log`, `rediscover_interval` (s), `deployments`. Voir
  [Serveurs Press](/fr/install/press).
  :::
::

## Contrôles

Chaque clé est optionnelle ; les valeurs par défaut sont celles de l'exemple. `"tls": false` (et de
même pour les autres) désactive un contrôle.

| Clé | Réglages |
|---|---|
| `rq` | `long_job_minutes` (30) |
| `backups` | `enabled`, `interval` (600 s), `press` (ignorer les benches Press), `dirs` (répertoire de sauvegarde par site) |
| `tls` | `interval` (3600 s), `port` (443), `timeout` (5 s), `connect_host` (par exemple `127.0.0.1` pour contrôler le nginx local), `domains` (ajouter), `exclude` (retirer) |
| `mariadb` | `cli` (sinon `mariadb` / `mysql`), `host`, `port`, `user`, `password`, `defaults_file` : un utilisateur de supervision pour l'état de la réplication |
| `processes` | `manager` : `auto`, `supervisor` ou `systemd` |
| `versions` | `interval` (3600 s) |
| `site_settings` | `interval` (3600 s) |
| `exposure` | `interval` (600 s), `ports` (ports supplémentaires à compter) |
| `integrity` | `interval` (900 s), `full_scan_interval` (86400 s), `server_paths` (`null` : `/etc/nginx` et `/etc/supervisor`) |
| `suricata` | `eve_log`, `max_priority` (3) |
| `wazuh` | `alerts_log`, `min_level` (7), `exclude_groups` (`["sca"]`) |
