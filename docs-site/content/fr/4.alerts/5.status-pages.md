Une **Wolf Status Page** montre l'état de santé d'un site aux invités, à l'adresse
`/wolf-status/<slug>`. Elle est facultative (opt-in).

## Créer une page

| Champ | Signification |
|---|---|
| **Titre** | Affiché en haut de la page. |
| **Slug** | L'adresse : `https://wolf.example.com/wolf-status/<slug>`. |
| **Site** | Le site dont les incidents sont affichés. |
| **Bench** | Optionnel : affiche aussi les incidents du bench. |
| **Description** | Texte optionnel sous le titre. |
| **Jours d'historique affichés** | Jusqu'où remonte la liste des incidents résolus. |
| **Gravité minimale** | Les incidents d'une gravité inférieure ne sont pas affichés. |
| **Activé** | Tant que la case n'est pas cochée, l'adresse répond 404. |

## Ce que voient les invités

- Une bannière d'état général.
- Les incidents ouverts, et ceux résolus pendant le nombre de jours fixé par
  *Jours d'historique affichés*.
- Pour chacun : un titre, la gravité, un statut public (*Investigating*, *Identified*, *Resolved*)
  et les horaires.

Les hôtes, les règles, les résumés et les charges utiles ne quittent jamais le serveur.

::caution
Les titres internes nomment souvent des hôtes. Un incident s'affiche comme « Degraded performance »
ou « Service disruption » tant que vous ne renseignez pas son **Titre public**.
::
