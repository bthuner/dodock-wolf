Wolf Agent

Scrubbing

How the agent removes personal data and secrets from events before they leave the host.

Before an event is spooled or sent, the agent scrubs its title and every string in its payload: sample lines, tracebacks, messages, routes. It is on by default.

WhatBecomes
e-mail addresses, also URL-encoded (jane%40example.com)[EMAIL]
Authorization: / Proxy-Authorization: header values, Cookie: / Set-Cookie: values[REDACTED]
Bearer …, token <key>:<secret>, Basic … credentials[REDACTED]
JWTs (eyJ….….…)[JWT]
values of password, pwd, new_password, *_secret, *_token, api_key, sid, session_id, otp, signature, in query strings, forms, JSON or Python dict reprs[REDACTED]
card-like numbers (13–19 digits, Luhn-valid, issuer digit 2–6)[CARD]
IBAN-like strings (mod-97 checked)[IBAN]
IP addresses, only with "ips": true[IP:<8 hex>], a keyed hash, stable per agent

IP addresses

IPs are kept by default, because the SSH brute-force and "admin login from a new IP" rules are built on them. Turn ips on if addresses count as personal data for you and you can live without per-IP grouping in titles.

What never changes

Type, host, bench, site, timestamp and fingerprint. Fingerprints are computed from the raw lines before scrubbing, so grouping and deduplication on the Wolf site work the same either way.

Metrics carry no free text and are not scrubbed. Text you type yourself (mark-deployment --note) is sent as is.

Settings

/etc/wolf-agent/config.json
"scrub": {
  "enabled": true,
  "ips": false,
  "extra_patterns": [
    "internal-\\d{4}",
    {"pattern": "CUST-\\d{6}", "replacement": "[CUSTOMER]"}
  ],
  "keep": ["@dokos.io", "noreply@example.com"]
}
extra_patterns
array
More regexes: a string (replaced by [REDACTED]) or {"pattern", "replacement"}. Invalid ones are logged and skipped.
keep
array
Values never replaced: exact strings (case-insensitive), or @domain to keep every address at that domain, such as your own system mails.
enabled
boolean
"scrub": false or "enabled": false ships the lines as they are.

Run wolf-agent check to see exactly what would be sent.
